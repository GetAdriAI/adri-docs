# Explore code mining

Code mining documents the custom-code landscape in your SAP ECC or SAP S/4HANA system. It generates readable functional specifications and maps dependencies among custom objects, helping you understand what the code does and how the landscape is connected.

Adri AI also organizes custom code by SAP module, associated business process, and application category. These are classification views of the mined source code; code mining does not include process mining.

## Explore Code Mining deliverables in Adri AI

Adri AI includes a curated reference portfolio with hundreds of ABAP objects. Create your own demo project, copy the prepared Willow reference data, and inspect the Code Mining deliverables without connecting an SAP system.

:::tip Already set up?
**If you have already signed up for Adri AI and copied the Willow reference project, skip directly to [Step 3](#step-3-explore-documentation-and-the-source-dependency-graph).**
:::
