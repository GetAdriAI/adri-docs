## Adri reduced clean core migration planning from 16 weeks to 3

![Clean core migration planning with Adri](/img/case-studies/case-study-clean-core.png)

### Customer and SI partner

Multinational FMCG company · SAP Gold Partner

### Migration scope

SAP ECC and BW → SAP S/4HANA Private Cloud under RISE with SAP, BDC – Datasphere, and BTP

### Object count

About 4,000 technical objects

### Timeline

**Planned timeline before Adri:** 16 weeks  
**Actual timeline with Adri (including onboarding):** 3 weeks

### Task

Adri analyzed about 4,000 technical objects and delivered an actionable clean core migration plan in 3 weeks, including onboarding—81% less time than the planned 16 weeks. The plan connected legacy business logic and dependencies to standard replacements, modernization paths, and the clean core impact of migration decisions.

- **Mapped legacy business logic and dependencies:** Adri built the Context Engine that included each RICEFW object's business purpose, behavior, and dependencies on other objects and external systems.
- **Identified standard replacements and modernization paths:** Adri mapped candidates for replacement with standard capabilities in the target landscape and for modernization, including decoupling and moving to BTP.
- **Tracked clean core impact of migration decisions:** Adri created a dashboard showing clean core levels with each transformation decision.
