# Work with SAP PI/PO

Adri AI brings SAP PI/PO into the same VS Code workspace where you work with agents and SAP Integration Suite. Use the PI/PO integration to:

- browse design-time and runtime objects;
- develop new PI/PO integrations;
- inspect existing interfaces before changing them; and
- use a PI/PO interface as the source for an SAP Integration Suite migration.

## Set up PI/PO

Start by [connecting your PI/PO system](./set-up/connect-pi-po.md). The connection is personal to your Adri user and is not automatically shared with other project members.

## Use PI/PO

After connecting, learn how to [explore PI/PO and work with an agent](./use/explore-and-develop.md).

If your goal is migration, follow the complete guide to [set up PI/PO to Integration Suite migration](../integration-suite/set-up/pi-po-to-integration-suite-migration.md).
