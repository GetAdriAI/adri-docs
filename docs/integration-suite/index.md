# Work with SAP Integration Suite

Adri AI supports both PI/PO-to-Integration-Suite migration and greenfield SAP Integration Suite development. The SAP Integration Suite Toolkit lets agents build, deploy, migrate, and work with iFlows from your VS Code workspace.

## Set up SAP Integration Suite

Complete the focused setup pages in order:

1. [Request SAP Integration Suite access](./set-up/request-access.md).
2. [Add the Integration Suite Toolkit to your workspace](./set-up/add-toolkit.md).
3. [Connect SAP BTP Cloud Foundry](./set-up/connect-cloud-foundry.md).

For a single walkthrough that starts with signup and ends with an agent message, use [set up PI/PO to Integration Suite migration](./set-up/pi-po-to-integration-suite-migration.md).
