# Develop a new SAP Integration Suite integration

Adri AI also supports new SAP Integration Suite development; a PI/PO source interface is not required.

Before starting, [add the Integration Suite Toolkit](../set-up/add-toolkit.md) and [connect SAP BTP Cloud Foundry](../set-up/connect-cloud-foundry.md).

1. Open the workspace that contains the SAP Integration Suite package.
2. Create or open an **Adri Code Agent** session.
3. Select **Link systems** and enable the target Cloud Foundry sign-in.
4. Confirm that the SAP Integration Suite capabilities are enabled.
5. Describe the integration you want to build, including its trigger, source and target systems, data contract, mapping rules, security requirements, and expected deployment target.
6. Select **Send**.

Start with the business outcome and constraints. The agent can then clarify missing details before it creates or changes integration artifacts.
